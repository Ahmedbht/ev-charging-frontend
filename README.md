# EV Charging Station Finder - Frontend
A React frontend for the EV Charging Station Finder app. Displays real EV charging station data from Morocco.

# Tech Stack
-React
-Axios
-Recharts
-Lucide React
-React Spinners

# Features
-View all EV charging stations in Morocco
-Search stations by city
-Filter operational stations
-Analytics dashboard with charts
-Top 10 stations by charging points

# How to run locally
1.Clone the repo
2.Install dependencies: `npm install`
3.Run: `npm start`
